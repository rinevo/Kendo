ブラウザで手軽に遊べる、**読み合いと間合いの駆け引き**を極限まで追求した本格剣道シミュレーション＆対戦ゲームです。  
基本4打突（面・小手・胴・突き）の四すくみ理合に、固有必殺技の覚醒・崩し・応じ技・気合闘気、そして構えの予兆やAIの思考を読む心理戦を楽しめます。

さらに、廃部となった名門剣道部を再建して全国制覇を目指すドラマティックな**「全国制覇モード」**、道場の最高位を懸けて挑むストーリー連戦**「五人掛けの試練（免許皆伝）」**、SVGプロシージャル生成による**「生徒手帳＆顔写真システム」**、心揺さぶる**BGM音響＆リアルタイム音声合成**を完全搭載しています。

## ✨ ゲームのハイライト

### 🏯 2つのゲームモード

1. **🥋 全国制覇モード（廃部からの再起・高校剣道部シミュレーション）**
   - かつて全国に名を轟かせたものの廃部となっていた名門剣道部。プレイヤーは**1年生創設主将**として埃をかぶった道場を再建し、ゼロから全国制覇を目指します（創部プロローグイラスト付き）。
   - 1ヶ月4週のカレンダー制で部員たちに稽古をつけ、夏のインターハイ（個人戦）や春の全国選抜（団体戦）に出陣！
   - 部員不足時は他部（陸上・柔道・野球・吹奏楽・卓球・将棋）から**助っ人をダイレクト勧誘**可能。
   - 日々の鍛錬で眠っていた秘技が開眼する**「固有得意技（必殺技）覚醒システム」**。
   - 新歓・引退・新体制発足の世代交代セレモニーや、**全20種の高校生部活ライフ専用イラストイベント**を収録。3年生引退時には「次世代への継承」または「集大成の部活エンディング」を選択可能。全国大会優勝後は**主将試合の自動化（オート観戦・即時判定）**が解放！

2. **🏆 勝ち抜き五人掛けモード（免許皆伝・五人掛けの試練）**
   - 道場の最高位「免許皆伝」を懸け、同門・先輩・師範代の精鋭5人と勝ち抜き一本勝負！
   - テンポを損なわない会話ダイアログ（スキップ対応）と**各試練の専用対峙イラスト（全6点）**により、一戦ごとのドラマと剣の理念（交剣知愛）を体感。
   - 先鋒（健太）・次鋒（佐々木）・中堅（鬼塚）・副将（霞）・大将（龍禅）を打ち破ると、**「免許皆伝之証」授与式イラスト**、師範代からの祝辞、仲間たちの寄せ書き祝福カード、試練戦績エピローグが表示されます。

### 📇 生徒手帳 ＆ プロシージャル顔写真システム

外部画像ファイルに依存せず、ブラウザ上で無限のバリエーションをリアルタイム描画する**SVGプロシージャル顔写真生成エンジン（`FaceGenerator`）**を搭載。

- **個性豊かな証明写真アバター**: 肌色（色白〜剣道焼けの5種）、髪型・髪色、目・眉・口、制服（学ラン・ブレザー・道着）、表情をシード値から決定論的に生成。
- **生徒手帳モーダル**: 部員カードやライバル選手をクリックすると、本物の生徒手帳のような身分証明書UIが開き、顔写真・学年・ポジション・8軸パラメータ・得意技・パーソナリティを確認可能。
- **試合画面連動**: 立ち合い（試合）中の選手カード（赤・白）にも顔写真が反映され、対戦の臨場感が劇的に向上。

### ⚔️ 読み合いと間合いの「四すくみ」バトル

基本打突（面・小手・胴・突き）は四すくみ関係にあり、さらに「防御・気合」「崩し（体当たり）」、そして各剣士固有の「必殺技」が絡み合う奥深い駆け引きが展開されます。

```mermaid
flowchart TD
    subgraph 基本4打突["⚔️ 基本4打突（面・小手・胴・突き）"]
        Men["面"] -->|相性有利| Kote["小手"]
        Kote -->|相性有利| Do["胴"]
        Do -->|相性有利| Tsuki["突き"]
        Tsuki -->|相性有利| Men
    end

    Defend["🛡️ 防御・気合"]
    Break["💥 崩し（体当たり・HP0防止）"]
    Special["🔥 固有必殺技（気合3消費・無敵攻撃）"]

    基本4打突 -->|受け止める / 気合+1 & 次ターン応じ技| Defend
    Defend -->|ガード不能で崩す！ 1ダメ & 次ターン防御不可| Break
    Break -->|打突が先に入り迎撃される| 基本4打突
    Special ==>|完全無敵・防御貫通で特大ダメージ！| Defend
    Special ==>|相手のあらゆる技を粉砕！| 基本4打突
```

- **理合相性 ＆ パラメータ対決**: 面 ＞ 小手 ＞ 胴 ＞ 突き ＞ 面。同じ技同士は腕力・敏捷・技術のパラメータ判定勝負！
- **気合闘気システム**:
  - 気合1: パラメータ判定+5（同種技判定で優位）
  - 気合2: 与ダメージ+1 / 被ダメージ-1
  - 気合3: 与ダメージ特大 / 不動心（被弾時ダメージ半減） / **完全無敵・防御貫通の「固有必殺技」発動可能**
- **構え切替**:
  - **中段**: 全能力がバランス良く発揮される基本の構え
  - **上段**: 超攻撃型。面が2ダメージに強化され突きを被弾しやすい（防御不可）
  - **下段**: 後の先。防御・気合時にHPが小回復
- **鍔迫り合い**: 打突衝突で密着状態へ移行し、威嚇・突き放し・引き技の近接戦へ。
- **適応型AI**: ワンパターンな行動を繰り返すと、相手が学習して裏をかく見切りカウンターを発動！

### 🎵 臨場感を極める音響 ＆ 映像演出

- **厳格な剣道作法を再現した音声仕様**:
  - 攻撃成功時のみ技名（「めーん！」「こてー！」など）を発声。
  - 防御成功時、攻撃された側、失敗側は**完全無言**。
  - 崩し成功時および双方の気合激突時は迫真の掛け声**「ヤァァァ！」**がSEと完全シンクロ。
  - 相討ちは双方が攻撃を受けた側となるため**完全沈黙**。
- **シチュエーション別BGM**: 道場稽古、大会、立ち合い、免許皆伝授与式、表彰式まで専用BGMが滑らかにクロスフェード。
- **完全合成の審判号令**: Web Audio APIフォルマント合成により、「ハジメッ！」「一本！」の音声をブラウザ単体でリアルタイム生成。
- **Canvas 60fps アニメーション**: 竹刀のしなり、2ボーンIK、道着や袴の布揺れ、火花パーティクルを描画。

## 🛠️ 使用技術

- **Vanilla JavaScript (ES6+)**: フレームワーク非依存の軽量設計
- **SVG Procedural Generation**: 数学・シード値に基づく完全プロシージャル顔写真生成エンジン
- **HTML5 Canvas API**: 関節IK補間、布物理、パーティクル、高解像度描画
- **Web Audio API**: 審判号令・気合声のフォルマント合成、竹刀打突音のノイズ生成
- **HTML5 Audio API**: シームレスなBGMクロスフェード制御
- **Modern CSS3**: Glassmorphism、生徒手帳UI、Flexbox/Grid、Safe Area・モバイル完全対応
